# Revolt Hub Chhibramau 🚀

Official website for AK Enterprises – authorized Revolt Motors dealership in Chhibramau, Kannauj (Uttar Pradesh).

## ⚡ About
This project is a modern, responsive website built to showcase Revolt electric motorcycles and provide customers with an easy way to explore models, book test rides, and send enquiries.

## 🌍 Location
Chhibramau, Kannauj, Uttar Pradesh  
Serving nearby areas: Farrukhabad, Auraiya, Hardoi

## 🔥 Features
- Modern UI with smooth animations
- Showcase of Revolt electric bikes (RV1, RV1+, BlazeX, etc.)
- Bike specifications and pricing display
- Test ride & booking links
- Enquiry form for customers
- Mobile responsive design
- Fast loading and optimized layout

## 🛠️ Tech Stack
- HTML5
- CSS3
- JavaScript

## 🎯 Purpose
To create a strong online presence for Revolt Hub Chhibramau and help customers easily explore electric vehicle options.
